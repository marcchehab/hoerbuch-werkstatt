# KÖNIG ZHOU XIN
- Aussprache: Zhòu Xīn · Dschou Schin (auch Di Xin vo Shang)
- Zeichen: 纣辛
- Farbe: #7a1f1f
- Rolle: Spielfigur in «Three Body», Tyrann in der Pyramide
- Aussehen: reglos auf dem Thron, ausdrucksloses Gesicht
- Temperament: träge, gleichgültig, grausam ohne Leidenschaft
- Beziehungen: König Wen (lässt ihn zum Essen «einladen»), Fu Xi
- Erster Auftritt: Kap. 7

## Stimme
- Tonlage: tief, träge
- Tempo: langsam, gelangweilt
- Dialekt-Färbung: Züridütsch, gedehnt
- Sprachtics: Befehle «Re-hy-drie-re!» / «De-hy-drie-re!» als durchdringender Singsang
- Referenzzeile: «Jichang, setz dich. Es git grad öppis z ässe.»
